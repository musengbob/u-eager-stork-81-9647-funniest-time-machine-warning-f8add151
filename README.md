# Funniest Time Machine Warning Label

One line, 101 characters, the funniest warning label for a time machine — entered in the [make.fun bounty](https://make.fun/c/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151).

## The entry

> WARNING: If you meet yourself, do not make eye contact. One of you is lying about being the original.

101 characters, one line: a straight-faced safety notice about the oldest time-travel hazard — meeting your own duplicate — with the punch landing on the last few words, when the label quietly admits one of the two yous is an imposter and neither can prove which.

## Run

```sh
node main.ts   # writes the entry to /output/entry.txt
```

`main.ts` writes the line to `/output/entry.txt` and enforces the gate itself: 1–120 characters, a single non-blank line.
